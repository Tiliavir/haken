# ADR-20261104: *Focus* (today's list) without a daily reset

Status: Accepted

## Decision

- The smart list is called *Focus* (German *Fokus*): it holds more than what is due today, and "Today" stays the word for the due date.

- *Focus* has two parts, in this order:
  1. Open tasks **due today or overdue**, oldest due date first.
  2. Tasks the user **put on Focus**, most recently added first.
  Below them, collapsed: tasks completed today that were due or on Focus.
- A task put on Focus **stays there** until the user takes it off. There is no reset at midnight. A task that is due and on Focus shows once, in the first part.
- Stored as `X-HAKEN-MYDAY:<YYYYMMDD>`, the day it was put on Focus (used for the order). Adding it again keeps the first day. The value is validated like every interpreted property.
- Put on Focus: *Add to Focus* in the task screen, or drag a task row onto *Focus* in the sidebar. Take off: *Remove from Focus*. A task added inside *Focus* goes on Focus without a due date.
- Overdue dates are red (`--danger`, at least 4.5:1 in both schemes) in every list; a task due today shows an exclamation mark; a task on Focus shows a sun marker.
- Completing a repeating task on Focus advances it and leaves it on Focus.

## Why

- This is how the user works: today's must-dos at the top, the chosen tasks below, and the choice is not lost overnight.
- An `X-` property is the only option (no standard exists); other clients ignore and preserve it. A date instead of a flag gives a stable order and the history of the choice.
- Red keeps one meaning, "needs attention" (overdue, errors, destructive actions), so it stays a signal; the accent colour stays the only colour for everything else.
